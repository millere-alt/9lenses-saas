## 💡 Design Principles

### Color Application Strategy:
- **Cyan dominates** (55%) for backgrounds - creates clarity and calm
- **Teal provides structure** (30%) for headers and navigation - builds trust
- **Orange energizes** (15%) for CTAs and highlights - drives action

### Typography:
- **Font**: Arial (web-safe, universally compatible)
- **Headers**: Bold, 48-72px, Dark Teal (#1E6B8C)
- **Subheaders**: Semi-bold, 24-36px, Medium Teal or Amber Orange
- **Body**: Regular, 16-18px, Charcoal (#2C2C2C)

### Data Visualization:
- **Primary**: Medium Teal (#4A9BB8)
- **Accent**: Amber Orange (#F5A623)
- **Status**: Green/Yellow/Red for scoring
- **Multi-series**: Alternate teal and orange tones

## ✅ Customization Tips

### PowerPoint:
- Colors: Right-click shapes → Format Shape → Fill
- Logo: Insert → Pictures → Place in header
- Charts: Right-click → Edit Data
- Duplicate: Right-click slide → Duplicate Slide

### Website:
- Colors: Edit CSS variables at top of file
- Content: Replace text in HTML body
- Images: Add `<img>` tags in sections
- Links: Update `href="#"` with real URLs
