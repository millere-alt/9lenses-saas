## 📊 Usage Guidelines

### When to Use Each Color

**Light Cyan (#A8D8E8)**
- Large background areas
- Section backgrounds
- Matches book aesthetic
- Creates calm, open feeling

**Dark Teal (#1E6B8C)**
- Headers and navigation
- Dashboard frames
- Primary branding elements
- Text overlays on light backgrounds

**Amber Orange (#F5A623)**
- Call-to-action buttons
- Important highlights
- Key metrics and numbers
- Interactive elements

**Medium Teal (#4A9BB8)**
- Data visualization
- Charts and graphs
- Secondary CTAs
- Links and interactive text

**Status Colors**
- Green: High performance (scores 8-10)
- Yellow: Medium performance (scores 5-7)
- Red: Needs attention (scores 1-4)
